Tres movimientos, ninguna caja negra

Del archivo a la respuesta hay un solo camino, y puedes inspeccionarlo entero.

01

Sube

Arrastra un CSV, Excel o JSON al panel de fuentes. Se materializa en su propia base SQLite y se infiere el esquema: columnas, tipos y valores de ejemplo.

media/dbs/dataset_<id>.sqlite

02

Pregunta

Escribe como le hablarías a un analista. Un detector de intención elige el camino: SQL generado por un LLM local, o el motor estadístico si pides pronósticos, anomalías o segmentos.

recuerda las últimas 3 consultas — «¿y por mes?» funciona

03

Verifica

Toda respuesta trae su recibo: SQL o método, motor, tiempo y si vino del caché. Si una pregunta falla, recibes sugerencias para reformularla.

El LLM no entrena con tus datos

modelo

kimi-k2.7-code vía API OpenAI-compatible con retención 0 días: los prompts no se almacenan ni entrenan modelos.

datos

Cada dataset se materializa en un schema Postgres aislado. Las consultas corren con un rol de solo-lectura.

caché

1 hora por pregunta, invalidada al reprocesar la fuente. Un lock anti-stampede de 60 s evita duplicar llamadas al modelo.

bitácora

Éxitos, fallos y hits de caché quedan persistidos con su recibo. Tus métricas no mienten.
